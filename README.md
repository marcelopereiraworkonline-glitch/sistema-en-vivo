# Sistema en Vivo

MVP Next.js + Supabase. Incluye autenticación, organizaciones y eventos. Las funciones de participación, moderación, proyección y publicidad aún están en desarrollo y NO deben considerarse listas para producción.

## Variables

Copiar `.env.example` a `.env.local` y completar `NEXT_PUBLIC_SUPABASE_ANON_KEY` con la clave publicable del proyecto Supabase. Configurar ambas variables en Vercel.

## Inicio

`npm install` y `npm run dev`.

La base de datos está alojada en el proyecto Supabase `abfmusszgpotlyabaqxn`. Crear usuario en Supabase Auth para acceder. No subir claves privadas al repositorio.
